## Current use for LLM agents and MCP authorization

The term is now standard vocabulary in this area. The MCP specification's security best practices open their attack list with a "Confused Deputy Problem" section about MCP proxy servers and static OAuth client IDs, and use the term again for token passthrough (S:8). One gap worth knowing: the most widely read uses (AWS, MCP) never name Hardy. The MCP page links Wikipedia. The vocabulary has travelled further than the attribution.

## Antecedents

The capability concept predates him: Dennis and Van Horn's 1966 C-list of capabilities (S:6). Hardy's own text says he "had heard of capabilities and thought that they were neat and tidy" before the incident (S:1). The original contribution is the named failure pattern and the argument from it, while the mechanism is inherited. GNOSIS and KeyKOS were team efforts (Frantz, Landau, Jordan, Jonekait) (S:4, S:5), so any KeyKOS frame would be co-authored.
