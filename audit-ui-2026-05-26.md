# UI Audit — Thinker Distillery

> Iteration 3. Audit of the current site against the rubric from Iter-2 (C1–C23 + AC1–AC7). Per-page rubric scoring, cross-cutting patterns, severity-ranked dispositions. Evidence is screenshots (4 desktop captures at `/Users/juliedavila/.claude/jobs/fce49501/audit-screenshots/`) plus source code citations. No design solutions proposed here — those are Iter-4. *This audit feeds the design spec; the design spec drives the prototype.*

---

## Executive Summary

The current Distillery is **structurally strong and experientially under-developed.** It nails curatorial flatness, consistent thinker-page grammar, restrained chrome, restricted link density, and slow-reflective pacing. It misses on the parts of the rubric that translate "wisdom-formation" and "honors-thinkers" from structural commitments into experiential ones — there are zero images on the site (no portraits, no diagrams, no genealogy visualizations), no "you are here" location cue, no concept-page surface in site navigation, no pre-reading affordance, and the section-header style (aggressive uppercase sans-serif eyebrows) directly contradicts the feminine-intentionality criterion that hierarchy softness should come from weight axes, not capitalization.

Four findings rise to P0 (gate Iter-4 design proposals); four to P1 (significant gaps); the remaining findings are P2/P3 refinements.

**The one surprise the audit produced** — and the question that should be answered before Iter-4 starts — is that the Distillery's visual identity has diverged from Camila Hub's Mexican-modernist register (Azul Talavera + cenefa ornament + bilingual nav). The Distillery currently reads more like Stripe-Press-meets-Edge.org: paper/ink/sepia palette, Iowan Old Style serif, English-only nav. Both registers are defensible — but the choice should be conscious. Iter-2's research surfaced "Mexican-modernist visual identity in editorial-press context" as novel territory the Distillery could pioneer; the audit reveals the Distillery isn't currently occupying that territory either.

## Per-Page Findings

### Page 1 — Index (`/`)

*Evidence: `idx-desktop.png` + `src/pages/index.astro` + `src/styles/global.css`.*

**What works:**
- **C10 PASS** — Curatorial flatness. Seven thinkers listed alphabetically, identical visual treatment, no hero, no featured-pick. Reads as "all honored equally" — exactly the Stripe Press / Edge.org register.
- **C22 PASS** — Slow/reflective. No engagement bait, no infinite scroll, no sticky elements. Generous vertical breathing between entries (`padding: 18px 0` per `.thinker-index li`).
- **C2 PASS** — Body leading at `line-height: 1.55` (`global.css:44`), in target range.
- **C18 PASS** — Rhythm > decoration. Whitespace does the work, no ornamentation.
- **AC1 PASS** — No stereotyped feminine signaling. Palette is paper (`#fbfaf6`) + ink + sepia accents.

**What misses:**
- **C8 FAIL** — Honors-thinkers via portrait. No portraits, no faces, no visual identity per thinker. Edge.org pairs every thinker with a portrait — that gesture is what makes the listing feel like a roll-call of *people*, not a catalog of *names*. Currently the index reads as a reading list, not as a gallery of contributors.
- **C9 PARTIAL** — Mission-as-chrome. The tagline "Curated readings of practitioners whose ideas are worth metabolizing" *is* in the chrome, but it sits in a small italic sans-serif beside the site name — easy to miss. Edge.org's "To arrive at the edge of the world's knowledge…" lives beneath the masthead and is visually anchored. Current implementation passes the letter of the criterion but not the spirit.
- **C12 PARTIAL** — Concept pages exist (two: `coordination-headwind`, `adaptive-capacity`) but are not surfaced in site nav. No "Concepts" link in chrome. Discoverable only by drilling into a thinker page and following an inline link. Concept pages are second-class today, not first-class.
- **C13–C17 N/A** (no multimedia anywhere on the index) — this is its own pattern, see cross-cutting findings below.
- **C23 FAIL** — Bilingual co-presence. Site is English-only. Camila Hub does "Hilos · Semana · Apuntes · Borradores · Lecturas" as structural co-presence; the Distillery has only "Thinker Distillation" + "About →".

### Page 2 — Thinker (`/thinkers/alex-komoroske/`)

*Evidence: `thinker-desktop.png` + `src/pages/thinkers/[slug].astro`.*

**What works:**
- **C11 PASS — load-bearing strength.** Each thinker page is a "small multiple" of an 11-section template (`thinkers/[slug].astro:23-205`): Hero with 30-second-take, Who They Are, Core POV, Named Frames, Body of Work, Editorial Reading (Julie's lane), Where This Breaks, Adjacent Thinkers, Further In, Long Read CTA, optional notes. Once a reader internalizes the grammar of one page, every subsequent thinker page is "free" — Tufte's small-multiples principle (Iter-2 Lane 6) is directly applied.
- **C20 PARTIAL → leaning PASS in editorial lanes.** "From Julie's reading" is unambiguously first-person, and `julie-lane` styling (cream tint + sepia border) marks the voice editorially. The lane treatment is one of the design's quiet strengths.
- **C5 PASS** — No inline hyperlinks in dense body prose. Cross-references happen in dedicated structural lanes (Named Frames "also held by", Adjacent Thinkers, Further In). Body sections are uninterrupted.
- **C7 PASS** — Link density restricted. Body sections have zero links; structural lanes have 4-8 each — well within the 3-7 per-body-section ceiling.
- **C4 PASS** — Section breaks map to argument seams. The 11-section template segments by conceptual function (who/what/where/limits/adjacents), not by word count.

**What misses:**
- **C8 FAIL** — No thinker portrait. The thinker page is named "Alex Komoroske" with no face. For a project whose stated bias is *honoring thinkers*, this is the most direct gap. Edge.org pairs every conversation with a portrait that anchors the encounter.
- **C19 FAIL** — Hierarchy softness via weight axes. Section headers use ALL-CAPS sans + `letter-spacing: 0.12em` + `font-size: 0.78rem` (`global.css:147-157`). This is the OPPOSITE of "hierarchy softness via weight." Uppercase tracking is structurally aggressive — it shouts. Iter-2 Lane 5 (Bardzell, Lupton) was explicit: weight contrast, not letter-spacing tracking, is the feminist-HCI hierarchy move. The current eyebrow pattern is also visually monotonous — every section header looks identical, no editorial pacing.
- **C6 FAIL** — No location cue. The chrome shows "Thinker Distillation" + tagline. No breadcrumb, no "Thinker → Alex Komoroske" trail, no graph position indicator. A reader navigating deep into the concept-graph has no orientation scaffold (Iter-2 Lane 6 — Edwards & Hardman 1989 — was direct: visible location halves disorientation).
- **C3 FAIL** — No pre-training affordance. The 30-second-take is a *summary* (the take itself), not a *concept glossary*. A first-time reader meets "headwind frame," "essential vs accidental complexity," "Brooks's Law" inside body prose without scaffolding (Mayer & Pilegard pre-training principle).
- **C13-C17 N/A → P0 gap.** No portraits, no diagrams, no body-of-work cover thumbnails, no genealogy visualizations. The Named Frames section is purely typographic — no diagrammatic representation of the lineage. For a "honors-thinkers + purposeful multimedia + wisdom-formation" project, the absence is structural, not a styling choice.

### Page 3 — Concept (`/concepts/coordination-headwind/`)

*Evidence: `concept-desktop.png` + `src/pages/concepts/[slug].astro`.*

**What works:**
- **Five-lane template hits the rubric squarely.** Hero (eyebrow + name + gloss) → Genealogy (ordered attribution chain with kind-colored borders: original sepia, extended lighter) → Holders grid → Editorial Reading (Julie's slot, scaffolded with empty-state styling) → Where This Breaks + Still Load-Bearing → Adjacent Concepts.
- **C12 IMPLEMENTED but PARTIAL.** Concept pages are full-fledged content surfaces. But — see Index audit — they're not surfaced in site nav. Discoverability is the gap.
- **C8 PARTIAL** — At the concept level, "thinker portraits" become "primary source links" (`concepts/[slug].astro:65-69`). Each holder card carries a "primary source →" link. This is the honors-thinkers gesture at the concept page level. *Some* honoring infrastructure is here; portraits would deepen it.
- **C5 PASS** — Body lanes are link-restricted. Adjacent concepts lane is the link-dense surface; main body is clean.
- **C18 PASS** — Lanes use color-tint differentiation (cream/blue/break-tint) rather than ornament. The kind-colored borders on genealogy items (`global.css:608-618`) are a quiet, restrained variety that adds rhythm without decoration.
- **C20 PASS** — The "Awaiting Julie's editorial reading" empty-state is itself voice-of-the-frame — it marks the lane as Julie's, not Camila's, not the publication's. Writing-partner discipline visible in the chrome.

**What misses:**
- **C13-C17 N/A** — same multimedia absence. A "coordination headwind" concept page is a *natural diagram surface* — the headwind as a system diagram, the cost-of-coordination as a curve, the genealogy as a visual chain. None of it is here. The genealogy section is currently a typographic list; it could be a visual chain showing Brooks → Komoroske attribution kind transitions.
- **C19 FAIL** — Same uppercase eyebrow pattern (`CONCEPT`, `GENEALOGY`, `WHO HOLDS THIS FRAME`, etc.). Consistent with thinker page; consistent in being aggressive.
- **C6 FAIL** — No breadcrumb. A reader arriving at `/concepts/coordination-headwind/` from a Brooks page has no trail to find their way back without browser-back.

### Page 4 — Long-Read Chapter (`/thinkers/alex-komoroske/long-read/01-the-diagnosis/`)

*Evidence: `longread-desktop.png` + source.*

**What works:**
- **C1 PASS** — Body measure controlled by `p { max-width: 64ch }` (`global.css:160-161`), comfortably in the Bringhurst 45–75 cpl range. Long-read is the surface where this matters most.
- **C2 PASS** — Same 1.55 leading. Good for sustained reading.
- **C22 PASS** — No scroll-progress, no related-content sidebars, no floating nav. Just text on cream paper. Skulmowski & Xu 2022 (interface-induced load) — the long-read chapter respects this principle better than any other page on the site.
- **C5 PASS** — Body is link-free. References, if any, must move to a dedicated section.
- **C4 PASS** — Section breaks ("The clean diagnosis", "How coordination headwind actually feels", etc.) map to argument seams.

**What misses:**
- **C3 FAIL — most acutely.** Long-read is exactly where pre-training (concept glossary, key-terms sidebar) would do the most work. A reader landing on chapter 1 of a Komoroske long-read meets "coordination headwind," "slime mold," "value of a thing" without scaffolding. Mayer & Pilegard's principle predicts measurable retention cost.
- **C13-C17 N/A → most acutely.** A 6,000-word essay on coordination dynamics is a natural diagram surface. None of the long-read's three foundational metaphors (headwind, slime mold, gravitational pull) is visually rendered. The page is pure body text on cream paper.
- **C6 FAIL** — No "chapter 1 of N" indicator within the long-read. The reader can't tell where they are in the long-read sequence without scrolling back to the long-read index.
- **C8 N/A** — Long-read is the thinker's voice, not the thinker's portrait surface. But a small portrait + name in the chrome of the long-read chapter would anchor the encounter editorially.
- **C11 PARTIAL** — The long-read is structurally different from the thinker-page template. Inconsistent with the small-multiples principle. Defensible (long-form is a different genre), but worth a deliberate design decision.

## Cross-Cutting Patterns

**Pattern 1 — Multimedia is structurally absent (P0).** Zero portraits, zero diagrams, zero illustrations, zero embedded video or audio. The page sources confirm this is by current design, not by template — the templates don't have multimedia slots. For a project whose four named biases include *purposeful multimedia in service of helping the user grow and learn*, this is the largest single gap surfaced by the audit. The Iter-4 spec must propose specific integration patterns (portrait surface, genealogy diagram surface, concept-graph viz surface, when video/audio earns placement).

**Pattern 2 — Location cues are absent (P0).** No breadcrumb, no "you are here in the graph," no chapter-N-of-M, no concept-cluster indicator. Iter-2 Lane 6 (Edwards & Hardman 1989; Amadieu 2009) was direct: visible location measurably halves disorientation. The Distillery's *whole point* is to encourage cross-thinker navigation; the absence of orientation scaffolding makes that navigation a tax on working memory.

**Pattern 3 — Concept pages exist but are second-class (P0).** Concept pages are content surfaces but not navigational surfaces. No "Concepts" link in chrome, no concept index, no concept search. They're discoverable only by drilling into a thinker page and following an inline link. Per the Iter-2 novel-territory finding (cross-thinker concept pages as first-class navigation surface — no reference site does this), the Distillery has the *content* primitive but not the *navigation* primitive.

**Pattern 4 — Section-header style runs counter to feminine-intentionality criteria (P1).** Uppercase + letter-spacing tracking + small sans-serif (`global.css:147-157`) is the visual eyebrow pattern site-wide. Iter-2 Lane 5 (Bardzell, Lupton) was explicit: hierarchy via weight contrast, not via uppercase. Current pattern is aggressive (capitals always read louder), monotonous (every section header looks identical), and dated (uppercase tracking has been the default "academic / institutional" register since print). C19 was the criterion that named this trap; the current implementation falls into it.

**Pattern 5 — Chrome is anonymous (P1).** "Thinker Distillation" + small italic tagline + "About →". No mission-statement-as-chrome (the Edge.org move where the tagline IS the visual anchor). No voice-of-the-frame (the publication's editorial voice in the chrome itself). No bilingual co-presence (Camila Hub does this; the Distillery doesn't). The chrome is functional but doesn't carry editorial identity — a reader landing on a thinker page can't tell from chrome what kind of publication this is.

**Pattern 6 — Wisdom-formation scaffolding is structurally absent (P1).** No concept glossary before long-read chapters (C3 fail). No "you are here" within long-read sequence (C6 fail). No progress through a thinker's body of work. No "next thinker to read after this one" affordance (the Further In lane does this for one thinker's body of work, not across thinkers). Each page assumes full prior context — Mayer & Pilegard's pre-training principle is the most-violated of the academic findings from Iter-2.

**Pattern 7 — Honors-thinkers achieved via *structure* but missed via *experience* (P1).** Curatorial flatness — PASS. Consistent grammar — PASS. Body-of-work surfacing — PASS. But the experiential markers of honoring (portrait, ceremonial register, voice-of-the-frame, anchor imagery) are absent. The current site honors thinkers the way a library catalog honors authors — by inclusion and consistency — rather than the way Edge.org honors them (by giving each one face, register, presence).

## Surprising Finding — Visual Identity Divergence from Camila Hub

This is the audit's "novel" observation, in the sense that Iter-2 didn't predict it.

**Camila Hub's visual identity:** Mexican-modernist palette (Azul Talavera `#2C4A6B`, Tierra de Oaxaca `#A04A2C`, Oro de Retablo, Cal Encalada, Tinta Sepia) + Cardo + Source Serif 4 + JetBrains Mono + Spanish-bilingual nav (Hilos · Semana · Apuntes · Borradores · Lecturas) + single cenefa SVG ornament 3× site-wide.

**Distillery's visual identity:** Paper (`#fbfaf6`) + ink (`#1a1a1a`) + sepia accents (`#6b5b2e` Julie-lane, `#8a3a2e` break) + Iowan Old Style serif + system sans + JetBrains Mono + English-only nav ("Thinker Distillation" + "About") + no ornament.

These are *different design languages*. The Distillery reads closer to Stripe-Press-meets-Edge.org register than to Camila Hub's Mexican-modernist register.

**The Iter-2 research surfaced "Mexican-modernist visual identity in editorial-press context" as novel territory.** The audit reveals the Distillery is not currently occupying that territory either. It's occupying the more conventional Anglophone editorial register — defensibly, calmly, and consistently — but not the territory the research named as open.

**This is a fundamental design-spec question — gates Iter-4.** Before Iter-4 designs any specific direction, Julie should decide:

- **(a) Align with Camila Hub's Mexican-modernist register** — palette + bilingual nav + cenefa ornament adapted for editorial-press context. Pioneers the novel territory Iter-2 named. Bigger lift but stronger identity.
- **(b) Maintain the current Anglophone-editorial register** — paper/ink/sepia + Iowan + English. Calm, consistent, doesn't pioneer novel territory. Smaller lift.
- **(c) Hybrid** — Mexican-modernist accents (palette, maybe ornament, maybe Spanish-as-secondary in select chrome) layered over the current editorial-press structure. Risk: dilutes both.

This is not a styling question. It's a positioning question — what kind of publication the Distillery wants to be. The four named biases (wisdom-formation, honors-thinkers, purposeful multimedia, feminine intentionality) can be implemented in either register; the *cultural identity* of the publication is the choice.

## Accessibility + Semantic HTML (added post-advisor-pass)

> **Advisor caught this gap.** The original audit focused on the four named biases and undercounted accessibility/semantic findings. Re-running with explicit checks.

**What works (verified):**
- `<html lang="en">` PASS (`Base.astro:14`)
- Exactly 1 `<h1>` per page on all 4 audited pages PASS
- `<header>`, `<main>`, `<footer>`, `<article>` landmarks present (`Base.astro:24,31,35`; thinker/concept templates wrap in `<article>`)
- Body text contrast: `--ink #1a1a1a` on `--paper #fbfaf6` = **~14.5:1** PASS (WCAG AA 4.5:1)
- Soft text contrast: `--ink-soft #3a3a3a` on paper = ~10.5:1 PASS

**What misses — promoted into severity table:**
- **F16 NEW P0** — **No `:focus-visible` styles defined anywhere in `global.css`.** Keyboard navigation has no visible focus indicator. WCAG 2.4.7 (Focus Visible, Level AA) FAIL. Any user navigating via keyboard cannot tell what's focused.
- **F17 NEW P1** — **No skip-to-content link.** Screen-reader users must tab through the chrome on every page. Standard accessibility primitive missing.
- **F18 NEW P1** — **No `<nav>` landmark element.** Site has `<header>` chrome but no `<nav>` inside. Screen-reader users lose the canonical landmark for navigation. (Currently the chrome has one home link and one tagline — calling it "nav" would be charitable, but if Iter-4 adds Concepts/About nav links, the landmark becomes load-bearing.)
- **F19 P1** — **Inconsistent link affordance.** No bare `a` styling rule in `global.css`. Hover/visited states defined on only 3 specific link classes (`.genealogy-name:hover`, `.holder-name a:hover`, `.concept-page-link:hover`); other links have no hover/focus/visited feedback. Affordance is per-context rather than systematic.
- **F20 P3** — Muted text contrast (`--ink-muted #6b6b6b` on paper) = ~4.6:1, *just above* WCAG AA 4.5:1 floor. Passes but borderline. Used for chrome tagline, metadata, eyebrow labels.

**Not audited this pass (carry to Iter-4 as gating items, per advisor):**
- Touch-target size on mobile (44×44px minimum)
- `prefers-reduced-motion` handling (no transitions currently defined, so moot — but becomes relevant in Iter-4 if motion lands)
- `aria-current="page"` on active nav items (moot until nav grows)
- Open Graph / Twitter Card metadata per page
- JSON-LD schema (Person for thinkers, Article for long-reads)
- Canonical URLs
- Sitemap.xml / RSS feed

## F11 Camila-Hub Divergence — 3-Fix Test Applied

The advisor pushed back on F11 being labeled a "prerequisite gating Iter-4." Test: can I name 3 specific Iter-4 fixes that would have to be REDONE if Julie picks "harmonize with Camila Hub" vs "let Distillery stand apart"?

1. **Color token layer.** Camila Hub palette is `#2C4A6B` (Azul Talavera) + `#A04A2C` (Tierra de Oaxaca) + `#B8956A` (Oro de Retablo) + `#F4EFE6` (Cal Encalada) + `#2A2520` (Tinta Sepia). Distillery's `--paper`, `--ink`, `--julie-tint`, `--frame-tint`, `--break-accent` are entirely different. If Iter-4 ships with Distillery's current tokens and then Julie flips direction, every component restyled.
2. **Typography stack.** Camila Hub uses Cardo + Source Serif 4 + JetBrains Mono. Distillery uses Iowan Old Style + system sans + JetBrains Mono. If Iter-4 designs hierarchy and rhythm against Iowan + system sans and then flips to Cardo + Source Serif 4, every typographic decision re-tuned.
3. **Chrome structure with Spanish co-presence.** Camila Hub's "Hilos · Semana · Apuntes · Borradores · Lecturas" structures the navigation. The Distillery's nav is "Thinker Distillation" + "About". If Iter-4 ships a chrome redesign in English-only and then Julie adds bilingual structure, the chrome is reshaped end-to-end.

Verdict: **token-layer divergence, not surface.** F11 stays as PREREQUISITE gating Iter-4. The advisor's check confirmed the framing.
